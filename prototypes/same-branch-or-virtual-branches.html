Same branch or virtual branches?

Two Claude Code sessions edit one shared working directory. When a session commits, where should its commit go? A: onto the one branch you're on, with a Session-Id trailer recording who made it. B: onto a virtual branch of its own, as in GitButler, with HEAD sitting on a merge of all the branches. The same edits and commits are replayed both ways, side by side. Watch the git log, whether one session's work makes a clean PR, and what happens when both sessions touch the same file.

Throwaway prototype for the ticket "Same branch or virtual branches". The conflict rule was checked against real git: changes on the same line or on neighbouring lines conflict (in both merge and cherry-pick), and one untouched line between them is enough to merge cleanly.
